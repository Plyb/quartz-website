This is a living collection of research libraries that I've built.

[typed-datasets](https://github.com/Plyb/typed-datasets): a well-typed wrapper around HuggingFace datasets (see [[A Call for Better Type Hints in AI Safety Tooling]])
[slurm-launcher](https://github.com/Plyb/slurm-launcher): Tiny helper that re-submits a Python script as a Slurm batch job when run on a login node.
[runlog](https://github.com/Plyb/runlog): Lightweight experiment-run logger with per-run output directories and metadata capture.
